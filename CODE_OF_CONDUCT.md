# Contributor Covenant Code of Conduct

We pledge to make participation in **Fleo by Flyweel** a welcoming, respectful, and harassment-free experience for everyone.

- Be respectful, constructive, and empathetic in issues, discussions, and pull requests.
- Focus on technical and editorial merit.
- Report unacceptable behavior to **hello@flyweel.co**.

Adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
